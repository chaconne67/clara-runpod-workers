# Clara RunPod workers

Private source repository for the Clara image/video canary worker images.

- `video`: LTX 10Eros, PromptRelay, two-pass upscale and RIFE dependencies
- `image`: Moody Krea 2, Ultimate SD Upscale and SeedVR2 dependencies

Model weights are not stored in this repository or container images. They are mounted from the existing RunPod network volume.
